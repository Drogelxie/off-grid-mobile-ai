About Remote Servers
Connect to LLM servers running on your local network, such as Ollama or LM Studio.

Make sure your server is running and accessible from your device. For security, only connect to servers on trusted networks.
📁 Work with Files on Your PC
Run an agent on your PC - Open WebUI, LangChain, or a similar framework - that has access to a folder on that machine. Add it here as a regular server.

The agent reads and writes files on the PC directly. The app acts as the chat interface; all file operations happen on the PC side. No Android file access needed.

Example: Ollama + Open WebUI on your PC with a folder tool configured. The AI can read, create, and edit files in that folder. The files never leave your local network.

⌁ Same WiFi network
1. Find your PC's local IP address:
   Windows: run ipconfig — look for IPv4 Address
   Mac / Linux: run ip addr
2. Use that IP with the server port:
   Ollama: http://192.168.1.X:11434
   LM Studio: http://192.168.1.X:1234
🛡 Outside your home - secure with Tailscale
1. Install Tailscale on your PC and this phone (tailscale.com - free)
2. Sign in with the same account on both devices
3. Your PC gets a Tailscale IP starting with 100.
4. Use that IP here: http://100.X.X.X:11434
   Encrypted via WireGuard. No port forwarding needed.
